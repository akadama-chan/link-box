# 🦀 用途別リンク箱 v1

繰り返し使うURLを、自由に作った「箱」に入れて定位置から開くためのGitHub Pages向け静的Webアプリです。

## v1の主な機能
- 箱の作成・編集・削除
- URL必須のリンクカード追加・編集・削除・箱間移動
- 箱／カードの任意並び替え（v1は安定性優先で ↑ ↓ ⇈ ⇊ ボタン方式）
- localStorage保存
- JSON全体バックアップ／読み込み・マージ
- ID衝突時「現在を残す／読み込み側を採用／どちらも残す」
- 箱衝突時はID変換表で読み込み側カードの所属を追従
- 別ツールJSONは「部屋が違います！」で拒否
- 現在の箱だけHTML書き出し
- リンク入り箱の削除時、HTML書き出しを選択可能
- JSON/HTMLファイル名の日付は端末ローカル日付
- PC／iPhoneレスポンシブ表示
- 🦀 favicon

## 保存について
登録データはGitHubには保存されず、使用端末のブラウザ側 localStorage に保存されます。ブラウザ保存を恒久保存とはみなさず、JSON書き出しを併用してください。

iPhoneではSafari版とホーム画面版で保存領域が分かれる場合があるため、本番データはホーム画面版に置く運用を推奨します。

## GitHub Pages
`index.html` / `style.css` / `app.js` / `README.md` をリポジトリへアップロードし、Settings → Pages → Deploy from a branch → `main` / `/ (root)` を選択します。
